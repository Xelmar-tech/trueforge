--- name: mission-planning description: Split a Mission into 2–5 independent, ordered tickets an agent can pick up without questions. --- ## When to use The Mission issue is labeled ready-for-planning and has no sub-issues. ## Ticket shape - Title: imperative, under 70 characters - Sections: Why · Scope · Acceptance criteria · Out of scope - Every acceptance criterion is verifiable ## Never - Plan twice. If sub-issues exist, comment and stop. - Invent code work for a documentation-only Mission.
