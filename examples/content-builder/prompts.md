# Prompts to try

Use these in the UI, or set `TRUEFORGE_PROMPT` when running the API or SDK examples.

## Blog post

> Write a 1,200-word article for engineering leaders explaining why agent harnesses matter once an AI agent moves from a prototype to production. Use a practical, direct tone. Research with Exa, support important claims with sources, and produce a polished HTML preview.

## Product launch package

> Create a launch package for an open-source agent harness aimed at platform engineering teams. Produce a technical blog post, a LinkedIn post, and a five-post social thread. Research the current agent framework landscape with Exa before writing and avoid generic AI marketing language.

## Opinionated comparison

> Write a balanced comparison of hosted agent harnesses and in-process agent frameworks for a staff engineer choosing an architecture. Cover deployment, tool security, persistence, observability, and operational ownership. Research current primary sources with Exa and clearly label trade-offs rather than declaring one universal winner.
