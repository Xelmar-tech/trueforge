Built-in GitHub tools per event source. Each active GitHub source now serves a stateless MCP
endpoint at `POST /api/v1/event-sources/{source_id}/mcp` whose tools (issues, sub-issues, labels,
comments) act with the App's installation token. The manifest callback registers a matching MCP
connector named after the source; `POST /api/v1/event-sources/{source_id}/connector` registers or
refreshes it for a source connected earlier. Drops the unused `@octokit/app` dependency in favour
of a `node:crypto` App JWT.
